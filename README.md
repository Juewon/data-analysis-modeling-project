# 대구시 교통사고 데이터를 활용한 피해 분석 및 예측 모델 개발

## 📌 프로젝트 개요
**DACON**에서 진행한 **대구 교통사고 피해 예측 AI 경진대회**에 참가해 교통사고 데이터를 활용한 **사고 위험도(ECLO) 예측 모델**을 개발하는 프로젝트를 진행했습니다. 데이터 분석을 통해 현황 및 EDA 분석을 통한 주요 사고 위험 요인 인사이트를 탐색하고 탐색된 인사이트를 활용해 인공신경망(ANN) 기반 ECLO 점수를 예측하는 모델을 구축했습니다.

 본 프로젝트는 멀티캠퍼스 **데이터분석&엔지니어 교육 과정**에서 세미프로젝트로 처음 진행했으나, 당시 결과물이 만족스럽지 않아 교육 수료 이후 **개인 프로젝트로 전반적인 내용을 새롭게 재구성**하였습니다.

## 🎴 데이터 셔플링 여부 결정 및 기본 분석 모델 선정
**XGBoost**, **LightGBM**, **ANN** 모델의 기본 구조를 활용해 데이터가 시계열적 특성을 갖고 있는지 확인하기 위해 데이터 분리 시, 각 모델별 `shuffle=False/True` 옵션을 적용해 단일 성능 측정을 비교했습니다.

단일 `RMSLE` 지표에 국한되지 않고 모델의 종합적 성능 비교를 위해 `MSE`, `RMSE`, `RMSLE`, `R²`를 함께 측정했습니다. 또한, 모델 간 공평한 성능 평가를 위해 각 지표를 정규화한 뒤 가중치를 적용한 `scoring_model` 함수를 설계했으며, 이때 가중치는 각각 `{'MSE': 0.2, 'RMSE': 0.2, 'RMSLE': 0.5, 'R2': 0.1}` 로 설정했습니다.

- **모델 성능 점수 계산 함수**
  ```
  def scoring_model(results):
    # 가중치 설정
    weights = {'MSE': 0.2, 'RMSE': 0.2, 'RMSLE': 0.5, 'R2': 0.1}

    # 정규화 함수
    # 평가지표 별 값의 범위를 통일하기 위해 Min-Max 스케일링 수행
    def min_max_normalize(series, is_better_lower=True):
      min_val = series.min()
      max_val = series.max()
      normalized = (series - min_val) / (max_val - min_val)

      # R2는 높을수록, MSE, RMSE, RMSLE는 낮을수록 성능이 좋은 특성을 반영
      if is_better_lower:
        return 1 - normalized
      else:
        return normalized

    # 정규화 적용
    df_normalized = results.copy()
    df_normalized['MSE'] = min_max_normalize(results['MSE'], is_better_lower=True)
    df_normalized['RMSE'] = min_max_normalize(results['RMSE'], is_better_lower=True)
    df_normalized['RMSLE'] = min_max_normalize(results['RMSLE'], is_better_lower=True)
    df_normalized['R2'] = min_max_normalize(results['R2'], is_better_lower=False)

    # 성능 종합 점수 계산
    # 평가지표별 Min-Max 스케일링 값 * 가중치
    df_normalized['Score'] = (df_normalized['MSE'] * weights['MSE'] +
                              df_normalized['RMSE'] * weights['RMSE'] +
                              df_normalized['RMSLE'] * weights['RMSLE'] +
                              df_normalized['R2'] * weights['R2'])


    results['Score'] = df_normalized['Score']

    # 점수에 따라 모델 정렬 (내림차순)
    results = results.sort_values(by='Score', ascending=False).reset_index(drop=True)

    return results  
  ```

- **셔플링 여부에 따른 모델별 성능 점수(Score) 측정 결과**
  ![shuffle perform](./imgs/shuffle_perform.png)

## 🔎 ANN Layer·LR 최적화
파생변수 추가 및 피처 변환에 따른 성능 변화를 정확히 검증하기 위해, Optuna 기반 최적 `학습률(LR)`과 `층(Layer)` 구성을 탐색하여 모델의 기본 구조를 확립했습니다.

- **최적화 수행 방식**
  - Optuna 활용 Layer, LR에 대한 하이퍼파라미터 탐색을 통한 최적화 수행
  - 탐색 목표 : RMSLE 최소화 (`direction='minimize'`)
  - 탐색 횟수 : 50회 (`n_trials=50`)

- **탐색 공간(Search Space) 설정**
  | Hyperparameter   | Type         | Range / Candidates     | 설명 |
  |------------------|--------------|------------------------|------|
  | `n_layers`       | Integer      | 3 – 7                 | 은닉층 개수 |
  | `initial_units`  | Categorical  | unit_val 리스트 내 선택 | 첫 층 유닛 수 (예: 128, 256, 512 등) |
  | `min_units`      | Categorical  | {16, 32}              | 마지막 층 최소 유닛 수 |
  | `learning_rate`  | LogUniform   | 1e-5 – 1e-2           | Adam 학습률 |
  - Epoch: 200 / EarlyStopping: `patience = 20`, `restore_best_weights=True`
  - 데이터 분할: Train(2019-2020), Val(Train의 20%), Test(2021)
  - 탐색 후 상위 성능 모델을 기준으로 반복 학습(5회)을 수행하고, 각 평가지표별 성능 평균을 통한 일반화 성능 점수를 계산해 평가해 최적 학습률(LR), 층(Layer) 구성 선정

**💡 주요 인사이트**   
- 최적 탐색 결과 `64–32` 구조와 학습률 `0.001`이 채택되었으나, 기본 모델과 성능 차이는 크지 않았음
- 단순히 모델을 복잡하게 하기보다 **손실 함수·활성화 함수 등 다른 하이퍼파라미터 탐색**이 필요함

## 🔄 최적 종속변수 변환 방법 및 손실함수 선정
ECLO 종속변수의 분포를 분석한 결과, **오른쪽으로 긴 꼬리를 가진 비대칭 분포(Positive Skewness)** 임을 확인하였습니다. 이에 따라 `로그`, `제곱근`, `박스-콕스(Box-Cox)`, `로그-제곱근` 변환을 적용하고, 각 변환 방식별 일반화 성능을 비교했습니다.

또한, 각 변환 방법별로 `MAE`, `RMSE`, `MSE`, `Huber` 손실함수를 적용한 **일반화 성능**(반복 성능 측정 10회)을 측정하였으며, 이를 통해 **최적 종속변수 변환 방법과 손실함수 조합**을 선정했습니다.

공식 평가 지표인 RMSLE는 학습 과정에서 **NaN값**이 과도하게 발생해 안정적인 학습이 어려웠기 때문에 손실 함수 실험 목록에서 제외했습니다.

- **종속변수(ECLO) 데이터 분포**

  최대값(74)이 매우 크고 이상치가 다수 존재하는 **Positive Skewness** 분포 형태를 확인

- **변환 방법에 따른 손실함수 별 성능 측정 결과**
  ![eclo loss scale method perform](./imgs/loss_func_eclo_trans.png)

실험 결과, 종속변수인 ECLO에 **제곱근 변환**을 적용하고 `Huber Loss(delta=1.0)`를 사용한 모델이 가장 우수한 일반화 성능을 보였습니다. 이에 따라 이후 분석 및 모델 성능 측정 과정에서 ECLO에 제곱근 변환을 반영하여 **이상치 영향을 완화한 상태**로 분석을 진행했으며, 최종적으로 모델의 기본 손실함수로 `Huber Loss(delta=1.0)`를 채택했습니다.

EDA 결과를 기반으로 통계적으로 유의하지 않은 변수에 대한 제거 및 상대적으로 사고 발생 건수가 작은 범주에 대한 범주 결합, 범주 수가 많고 유의한 변수 대상으로 다변량 군집분석을 통한 위험도 구분 등의 조합에 대한 일반화 성능 비교를 통해 모델 성능을 개선했습니다.

#### 5. 훈련 전용 피처 기반 파생변수 추가에 따른 성능 분석
훈련 데이터에만 존재하는 피처는 테스트 데이터에서 사용할 수 없기 때문에 그대로 활용하기 어렵습니다. 따라서, 해당 피처 내 고위험 범주가 발생할 확률을 기반으로 한 파생변수 생성 방식을 적용했습니다.

- **확률 기반 고위험 범주 파생변수 생성 절차**
  1. **기준 변수 선정**: 훈련·테스트 데이터 모두에 존재하는 공통 변수를 ECLO에 대해 타겟 인코딩하고, 훈련 전용 피처를 종속변수로 설정하여 **설명력이 가장 높은 변수를 기준 변수**로 채택

  2. **고위험 범주 정의**: ECLO 통계량 기반 군집 분석을 수행해 **고위험 ECLO 군집을 식별**하고, 해당 군집에 속하는 비율이 높은 범주를 `고위험 범주`로 정의

  3. **확률 계산**: 각 훈련 전용 피처별로 연관성 높은 기준 변수와 결합하여, `고위험 범주`가 **발생할 확률을 산출**

## 🤖 Model Engineering
피처 엔지니어링 과정을 통해 최종 결정된 최적 피처 조합을 기반으로 Optuna 기반 하이퍼파라미터 최적화(HPO) 기법을 사용해 모델 구조 최적화를 수행했습니다.

- **목표** : RMSLE 최소화(`direction='minimize'`)
- **탐색 횟수** : 80번(`n_trials=80`)

- **탐색 공간 설정**
  | 하이퍼파라미터 | 탐색 범위 / 값 | 설명 |
  |----------------|----------------|------|
  | **n_layers** | `Int[3, 7]` | 은닉 레이어 개수 |
  | **initial_units** | `Categorical[unit_val]` *(예: [64, 128, 256, 512])* | 첫 번째 레이어 유닛 수 |
  | **learning_rate** | `Float[1e-4, 1e-2] (log)` | 학습률 |
  | **min_units** | `Categorical[16, 32]` | 레이어 축소 시 최소 유닛 수 |
  | **batch_size** | `Categorical[32, 64, 128]` | 배치 크기 |
  | **activation** | `Categorical['relu', 'softplus', 'elu']` | 활성화 함수 |
  | **loss** | `Categorical['mse', 'mae', 'rmse', 'rmsle', 'huber']` | 손실 함수 (공식 지표 RMSLE 포함) |
  | **optimizer** | `Categorical['adam', 'rmsprop', 'nadam']` | 최적화 알고리즘 |
  | **use_l2** | `Categorical[True, False]` | L2 정규화 적용 여부 |
  | **l2_lambda** | `Float[1e-3, 1e-1] (log)` *(if use_l2=True else 0)* | L2 정규화 계수 |

- **데이터 & 평가 프로토콜**
  - 데이터 분할: Train(2019~2020) / Val(Train의 20%) / Test(2021)
  - 평가 지표: RMSLE
  - Epochs: 200 / Early Stopping: patience = 20 / restore_best_weights=True
  - 인코딩 : 범주형 변수에 대해 훈련데이터 기반 원-핫 인코딩 사용
